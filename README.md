# script-audio-leitura
Implementando a leitura em áudio de páginas e notícias no site.
Esta é uma solução simples, leve e compatível com PHP/HTML/Bootstrap, que funciona bem em sites institucionais como os que eu costumo desenvolver.
A melhor abordagem nesse caso é usar a API nativa de voz do navegador (Speech Synthesis) — não precisa servidor extra nem custos.

🎧 Script de Leitura em Áudio para Páginas e Notícias

Este script:

- ✅ Lê o conteúdo da página
- ✅ Permite Play / Pause / Parar
- ✅ Permite escolher voz em português
- ✅ Funciona em Chrome, Edge e celulares
- ✅ Não depende de API paga
- ✅ Ideal para páginas estáticas e notícias
